📖 使用说明 & API 配置指南

基础功能（无需 API Key）：

  • 点击任意单词 → 朗读发音
  • 鼠标悬停单词 → 显示内置词典释义（700+ 词条）
  • 紫色下划线 = 词典中有该词
  • 右键点击单词 → 翻译该词 / 加入生词本

在线翻译功能（需要配置 API Key）：

  • 点击「翻译全文」→ 整段德文翻译成中文
  • 点击每句旁的「译」按钮 → 单句翻译
  • 右键单词 → 「翻译该词」→ 调用在线 API 查词

推荐 API 服务对比：

服务免费额度德语质量获取方式
DeepL50万字符/月⭐⭐⭐ 最佳deepl.com/pro-api
Microsoft200万字符/月⭐⭐⭐ 很好Azure 认知服务
LibreTranslate完全免费⭐⭐ 可用自托管或使用公共实例

DeepL 配置示例：

服务: DeepL
API Key: 你的 DeepL API Key（以 :fx 结尾的是免费版）

Microsoft 配置示例：

服务: Microsoft Translator
API Key: 你的 Azure Translator Key
（区域通常设为 global 即可）

LibreTranslate 配置示例：

服务: LibreTranslate
API URL: https://libretranslate.de（或你自己的实例）
API Key: 留空（公共实例通常不需要）

隐私说明：API Key 仅保存在浏览器本地（localStorage），不会上传到任何服务器。
