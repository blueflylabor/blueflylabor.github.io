📖 使用说明

操作方式：

  • 单击单词 → 朗读发音 + 显示 MyMemory 中文翻译（已缓存的直接显示）
  • 右键单词 → 菜单：翻译该词 / 朗读 / 加入生词本
  • 悬停单词 → 显示提示（如果已缓存则显示翻译）
  • 「译」按钮 → 翻译整句
  • 「翻译全文」 → 逐句翻译整个文档

关于 MyMemory API：

  • 免费翻译 API，无需注册，浏览器直接调用
  • 每天约 5000 字符免费额度（按 IP 计算）
  • 翻译结果自动缓存到浏览器本地，避免重复调用
  • 单次请求限 500 字节，超长句子会自动分段翻译

文件上传：支持 .txt .md .html，自动提取文本并分词
